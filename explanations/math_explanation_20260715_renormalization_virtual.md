# なぜ「メソン（仮想粒子）」だけを場の演算子にしたのか？

このドキュメントでは、三点関数 $\widetilde{\Gamma}'(p', p, q)$ の定義において、核子（フェルミオン）をオンシェルにし、メソンだけをオフシェル（仮想粒子、すなわち場の演算子 $\phi$）として残した理由を、ディラック代数と物理的測定の観点から解説します。

---

## 1. 理由の結論

メソンだけを仮想粒子（場の演算子）として扱い、核子をオンシェルにした理由は、以下の2点に集約されます：

1. **ディラックスピノルの行列構造を簡約化するため（代数的な理由）**:
   複雑なディラック行列（16通りや42通りなど）を $G(q^2) i \gamma_5$ という1つの項に簡約化するためには、**2本のフェルミオン線（核子）の両方がオンシェル（質量殻上）にあること**が数学的に必須だからです。
2. **実際の散乱プロセス（メソン交換）と直接対応させるため（物理的な理由）**:
   実験的に測定可能なプロセス（例： $N + N \to N + N$ 散乱）において、交換されるメソンはまさに**仮想粒子（オフシェル）**であり、核子は**物理的な外線粒子（オンシェル）**だからです。

---

## 2. 代数的な理由：フェルミオンのオンシェル化が必須であること

三点頂点 $\widetilde{\Gamma}'(p', p, q)$ は、2本のフェルミオン線（運動量 $p, p'$）と1本のメソン線（運動量 $q$）が結合しています。

もし、メソンをオンシェル（$q^2 = \mu^2$）にし、フェルミオンの片方（例えば $p'$）をオフシェル（仮想粒子）のままにしておこうとすると、どうなるでしょうか？

この場合、頂点関数は以下のようになります：
$$\left. \widetilde{\Gamma}'(p', p, q) (\not p + m) \right|_{p^2 = m^2, q^2 = \mu^2}$$

ここでは、左側のフェルミオン $p'$ がオンシェルではないため、左側から射影演算子 $(\not p' + m)$ で挟むことができません。ディラック方程式 $\bar{u}(p') (\not p' - m) = 0$ が使えないため、以下のような簡約化が一切できなくなります：
- $\gamma_5 \not p' \to m \gamma_5$ のような簡約化が不可能になる。
- その結果、頂点関数には $\gamma_5, \gamma_5 \not p'$ などの様々な独立な行列構造がそのまま残ってしまい、これらを1つのスカラー関数だけで表すことが不可能になります。

したがって、**ディラック代数の対称性（パリティ）とディラック方程式を用いて、頂点関数の行列構造を1つのスカラー関数 $G(q^2)$ に閉じ込めるためには、2本のフェルミオン線（核子）の両方をオンシェルに置くことが数学的に絶対に必要**なのです。
そして、残されたメソン1本が必然的にオフシェル（仮想粒子、すなわち場の演算子 $\phi$）の役割を担うことになります。

---

## 3. 物理的な理由：メソン交換プロセスとの対応

3点すべての粒子を同時に物理的なオンシェルにすることは（エネルギー・運動量保存則から）不可能です。では、この定義した $G(q^2)$ はどうやって実験的に測定するのでしょうか？

コールマンは、実験的にアクセス可能な物理的プロセスとして **核子-核子散乱 ($N + N \to N + N$)** を挙げています。

```
     N (on-shell)             N (on-shell)
         \                       /
          \                     /
           \   q (virtual)     /
            *=================*   <-- vertex: nucleon (on) + meson (off)
           /                   \
          /                     \
         /                       \
     N (on-shell)             N (on-shell)
```

この散乱プロセスの最低次のツリーダイアグラム（$t$ チャンネルまたは $u$ チャンネル）では、1本のメソンが中間状態として交換されます。
このとき：
- 外線の4本の核子はすべて、実際の物理的粒子なので**オンシェル**（$p^2 = m^2$）です。
- 中間状態で交換されるメソンは、仮想粒子なので**オフシェル**（$q^2 = t \neq \mu^2$）です。

この交換プロセスの頂点に現れるのは、まさに**「2本のオンシェル核子」と「1本のオフシェル（仮想）メソン」の結合**です。

したがって、「核子2本をオンシェル、メソン1本をオフシェル（場の演算子）」とする頂点関数の定義は、実際の核子散乱実験で測定される物理的なメソン交換の頂点と、最も直接的かつ自然に対応しているのです。
これこそが、メソンだけを場の演算子（仮想粒子）として残した物理的な理由です。
