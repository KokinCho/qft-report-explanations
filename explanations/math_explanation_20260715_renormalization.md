# フェルミオン結合定数の繰り込み条件と散乱振幅の極に関する解説

このドキュメントでは、スピン $1/2$ フェルミオン理論における結合定数の繰り込み条件の導入背景と、射影演算子を用いた議論が物理的情報を失わない理由（散乱振幅の極の議論）について詳しく解説します。

---

## 1. なぜ射影演算子を挟んだ繰り込み条件が必要なのか？

### スカラー理論（復習）との対比
スカラー核子の理論（Model 3）では、1PI（1粒子既約）三点関数 $-i\widetilde{\Gamma}'(p^2, p'^2, q^2)$ は単一のスカラー関数でした。そのため、すべての粒子がオンシェル（質量殻上）にある点での値を直接用いて、結合定数 $g$ を以下のように定義できました：
$$\widetilde{\Gamma}'(m^2, m^2, \mu^2) = g$$
これによって、ラグランジアンの相互作用項に対応する反項 $E$ を一意に決定することができました。

### フェルミオン理論における困難
フェルミオン理論（核子がスピン $1/2$ で、相互作用が $i g \bar{\psi}\gamma_5\psi\phi$）では、1PI頂点関数 $\widetilde{\Gamma}'(p', p, q)$ は $4 \times 4$ 行列の構造を持ちます。
摂動の最低次（ツリーレベル）では、
$$\widetilde{\Gamma}'(p', p, q) = i \gamma_5 g + \mathcal{O}(g^3)$$
と極めて単純ですが、ループ補正（高次補正）を取り入れると、利用可能なベクトル $p^\mu, p'^\mu$ やディラック行列の組み合わせにより、以下のような多様な行列構造が生じてしまいます：
- $\gamma_5$
- $\gamma_5 \not p$
- $\gamma_5 \not p'$
- $\sigma^{\mu\nu} p_\mu p'_\nu \gamma_5$ など（最大で 16 通りの独立な構造）

もし、これらすべての行列構造の係数（形状因子）に対して個別に繰り込み条件を課そうとすると、条件の数が多すぎてしまいます。一方で、我々が調整できる反項（カウンターターム）はラグランジアン中の $\delta g i \bar{\psi}\gamma_5\psi\phi$（すなわち $\gamma_5$ に比例する項）のみです。したがって、すべての行列構造を個別に固定しようとすると、方程式が**過剰決定（overdetermined）**になってしまい、繰り込みが不可能になってしまいます。

### 解決策としての射影演算子
そこでコールマンは、外線フェルミオンがオンシェルにある物理的な状況に注目し、頂点関数をディラックの**射影演算子** $(\not p' + m)$ および $(\not p + m)$ で左右から挟んだオブジェクトを導入しました：
$$\left. (\not p' + m) \widetilde{\Gamma}'(p', p, q) (\not p + m) \right|_{p^2 = p'^2 = m^2}$$

オンシェル条件 $p^2 = p'^2 = m^2$ のもとでこの量を考えると、ローレンツ不変性、パリティ保存などの対称性から、行列構造が劇的に単純化され、**唯一のスカラー関数 $G(q^2)$ のみで完全に決定される**ことが示されます：
$$\left. (\not p' + m) \widetilde{\Gamma}'(p', p, q) (\not p + m) \right|_{p^2 = p'^2 = m^2} = (\not p' + m) i \gamma_5 (\not p + m) G(q^2) \tag{23.85}$$

これにより、複雑な行列構造を持つ頂点関数のうち、物理的に意味のある寄与を $G(q^2)$ という1つのスカラー関数に集約することができました。この $G(q^2)$ に対して繰り込み条件を課すことで、反項を一意に決定できるようになります：
$$G(\mu^2) = g \tag{23.96}$$

## 2. 射影演算子を挟むことで「物理的な情報」は失われないのか？（極の議論の解説）

「射影演算子で挟む」という操作は、行列の特定の成分だけを取り出し、他の成分を切り捨てる操作に相当します。一見すると、切り捨てられた他の行列構造の情報（物理的な散乱に影響するかもしれない情報）を無視してしまっているように見えます。

しかし、コールマンは**「オンシェル散乱振幅の極（ポール）の近傍を調べる限り、物理的な情報は一切失われていない」**ことを証明しています。

### 具体的なプロセス： $\phi + N \to \phi + N$ 散乱
下図のような $s$ チャンネル極を持つ散乱プロセスを考えます。

```
       q (meson)               q' (meson)
         \                       /
          \                     /
    =======\===================/=======  (nucleon line)
       p    \     p + q       /   p'
             1PI             1PI
             blob            blob
```

この散乱振幅のうち、中間状態の伝播関数と右側の頂点、および外線の初期状態スピノール $u(p)$ の組み合わせは以下の形をしています：
$$\widetilde{S}'(p+q) \widetilde{\Gamma}'(p+q, p, q) u(p) \tag{A}$$

ここで、中間状態の運動量は $p+q$ であり、その不変質量は $s = (p+q)^2$ です。
物理的な散乱において最も重要なのは、中間状態がオンシェルになり、伝播関数が極を持つ $s \to m^2$ の近傍での振る舞いです（極の残差が物理的な散乱断面積や結合定数を決定します）。

#### (1) 左側からの射影演算子の供給
$s \to m^2$ の極の近傍において、完全なフェルミオン伝播関数 $\widetilde{S}'(p+q)$ は以下のように振る舞います：
$$\widetilde{S}'(p+q) \approx \frac{i (\not p + \not q + m)}{s - m^2} \tag{23.87}$$
この式の分子に注目すると、極の近傍で自動的に **$(\not p + \not q + m)$** という因子が出現します。
これは、頂点関数 $\widetilde{\Gamma}'$ の左側に掛かる**左側射影演算子**そのものです。

#### (2) 右側からの射影演算子の供給
右側の外線核子はオンシェルで実在する粒子であるため、その状態スピノール $u(p)$ はディラック方程式を満たします：
$$(\not p - m) u(p) = 0 \implies \not p u(p) = m u(p)$$
これを用いると、次の関係式が成り立ちます：
$$\frac{\not p + m}{2m} u(p) = \frac{m + m}{2m} u(p) = u(p) \tag{23.88}$$
この関係式は、外線スピノール $u(p)$ の直前には、恒等的に何倍かの**右側射影演算子 $(\not p + m)$ を自由に挿入できる**ことを意味しています（物理的な状態に対して何も変化を与えません）。

#### (3) 合わせ技
これら (1) と (2) の事実を式 (A) に代入すると、極 $s \to m^2$ の近傍で以下のように変形できます：
$$\begin{aligned}
\widetilde{S}'(p+q) \widetilde{\Gamma}'(p+q, p, q) u(p) &\approx \frac{i (\not p + \not q + m)}{s - m^2} \widetilde{\Gamma}'(p+q, p, q) \left( \frac{\not p + m}{2m} u(p) \right) \\
&= \frac{i}{s - m^2} \frac{1}{2m} \left[ (\not p + \not q + m) \widetilde{\Gamma}'(p+q, p, q) (\not p + m) \right] u(p) \tag{23.89}
\end{aligned}$$

### この結果が意味すること
この式の右辺の大括弧 `[...]` の中身を見てください：
$$(\not p + \not q + m) \widetilde{\Gamma}'(p+q, p, q) (\not p + m)$$
これは、まさに我々が繰り込み条件を課すために定義した**「左右を射影演算子で挟んだ頂点関数」**そのものです（中間状態がオンシェルに近づく極限 $s \to m^2$ において、中間状態の運動量 $p+q$ の二乗も $(p+q)^2 \to m^2$ となり、オンシェル条件を満たします）。

つまり、**「物理的な散乱プロセスの極の残差を計算するとき、伝播関数とディラック方程式の性質によって、射影演算子が自動的に頂点関数を挟み込む」**ことになります。

したがって：
- 射影演算子によって消去されてしまうような他の行列構造は、オンシェル物理（極の残差）には一切寄与しません。
- 散乱の物理的情報を担うのは、射影演算子で挟まれた部分（すなわちスカラー関数 $G(q^2)$）だけです。
- ゆえに、射影演算子で挟んだ量を使って繰り込み条件を課すことは、物理的情報を一切失うことなく、かつ方程式を過剰決定にしない、極めて合理的で賢い選択なのです。
