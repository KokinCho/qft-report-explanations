# 三粒子同時オンシェル条件を満たす複素運動量の具体的な構成と計算

このドキュメントでは、初期核子オンシェル（$p^2 = m^2$）、中間状態オンシェル（$p_I^2 = (p+q)^2 = m^2$）、およびメソンオンシェル（$q^2 = \mu^2$）を同時に満たす具体的な複素運動量の組 $(p^\mu, q^\mu)$ を計算し、構築します。

---

## 1. 運動量のフレーム設定

計算を最も単純にするために、初期状態の核子が静止しているフレーム（複素空間における静止系）を採用します。
初期核子の 4元運動量を以下のように置きます：
$$p^\mu = (m, 0, 0, 0) \tag{1}$$

このとき、初期核子のオンシェル条件は自動的に満たされます：
$$p^2 = (p^0)^2 - \mathbf{p}^2 = m^2 - 0 = m^2$$

次に、メソンの 4元運動量を以下のように置きます：
$$q^\mu = (q^0, q^1, q^2, q^3) \tag{2}$$

---

## 2. 方程式のセットアップ

満たすべき条件は以下の2つです：
1. **メソンのオンシェル条件**:
   $$q^2 = (q^0)^2 - (q^1)^2 - (q^2)^2 - (q^3)^2 = \mu^2 \tag{3}$$
2. **中間状態 $p_I = p + q$ のオンシェル条件**:
   $$p_I^2 = (p+q)^2 = p^2 + q^2 + 2p \cdot q = m^2 \tag{4}$$

式 (4) に $p^2 = m^2$ および $q^2 = \mu^2$ を代入すると：
$$m^2 + \mu^2 + 2p \cdot q = m^2 \implies 2p \cdot q + \mu^2 = 0 \tag{5}$$

ここで、式 (1) の $p^\mu = (m, 0, 0, 0)$ を用いて内積 $p \cdot q$ を計算します：
$$p \cdot q = p^0 q^0 - \mathbf{p} \cdot \mathbf{q} = m q^0$$

これを式 (5) に代入すると、$q^0$ が一意に定まります：
$$2m q^0 + \mu^2 = 0 \implies q^0 = -\frac{\mu^2}{2m} \tag{6}$$

---

## 3. 複素空間運動量の決定

定まった $q^0$ をメソンのオンシェル条件（式 (3)）に代入します：
$$\left( -\frac{\mu^2}{2m} \right)^2 - \mathbf{q}^2 = \mu^2 \implies \mathbf{q}^2 = \frac{\mu^4}{4m^2} - \mu^2 = \mu^2 \left( \frac{\mu^2}{4m^2} - 1 \right) \tag{7}$$

ここで、通常の物理的な系（例：核子 $m \approx 940 \text{ MeV}$, パイ中間子 $\mu \approx 140 \text{ MeV}$）では、$\mu < 2m$ であるため、
$$\frac{\mu^2}{4m^2} - 1 < 0$$
となります。したがって、式 (7) の右辺は**負の実数**になります。
実数の空間ベクトルでは $\mathbf{q}^2 \ge 0$ なので解はありませんが、**純虚数の空間運動量**を導入することで解が存在します。

空間運動量の方向を $z$ 方向（第3成分）のみと仮定し、以下のように置きます：
$$q^1 = 0, \quad q^2 = 0, \quad q^3 = i k \quad (k \in \mathbb{R}) \tag{8}$$

このとき、空間運動量の二乗は $\mathbf{q}^2 = (i k)^2 = -k^2$ となり、式 (7) は以下のようになります：
$$-k^2 = \mu^2 \left( \frac{\mu^2}{4m^2} - 1 \right) \implies k^2 = \mu^2 \left( 1 - \frac{\mu^2}{4m^2} \right) \tag{9}$$

$\mu < 2m$ より右辺は正の実数なので、実数 $k$ は以下のように定まります：
$$k = \mu \sqrt{1 - \frac{\mu^2}{4m^2}} \tag{10}$$

したがって、求めるメソンの複素運動量 $q^\mu$ は以下のようになります：
$$q^\mu = \left( -\frac{\mu^2}{2m},\, 0,\, 0,\, i \mu \sqrt{1 - \frac{\mu^2}{4m^2}} \right) \tag{11}$$

---

## 4. 得られた複素運動量のセットの検証

構築した以下の組が、すべてのオンシェル条件を満たしているか検証します：
$$p^\mu = (m,\, 0,\, 0,\, 0)$$
$$q^\mu = \left( -\frac{\mu^2}{2m},\, 0,\, 0,\, i \mu \sqrt{1 - \frac{\mu^2}{4m^2}} \right)$$

### 検証(A): $p^2 = m^2$
$$p^2 = m^2 - 0^2 = m^2 \quad (\text{OK})$$

### 検証(B): $q^2 = \mu^2$
$$q^2 = (q^0)^2 - (q^3)^2 = \left( -\frac{\mu^2}{2m} \right)^2 - \left( i \mu \sqrt{1 - \frac{\mu^2}{4m^2}} \right)^2$$
$$= \frac{\mu^4}{4m^2} - \left( - \mu^2 \left( 1 - \frac{\mu^2}{4m^2} \right) \right) = \frac{\mu^4}{4m^2} + \mu^2 - \frac{\mu^4}{4m^2} = \mu^2 \quad (\text{OK})$$

### 検証(C): $p_I^2 = (p+q)^2 = m^2$
中間状態の運動量は、
$$p_I^\mu = p^\mu + q^\mu = \left( m - \frac{\mu^2}{2m},\, 0,\, 0,\, i \mu \sqrt{1 - \frac{\mu^2}{4m^2}} \right)$$
です。その二乗を計算すると：
$$p_I^2 = \left( m - \frac{\mu^2}{2m} \right)^2 - \left( i \mu \sqrt{1 - \frac{\mu^2}{4m^2}} \right)^2$$
$$= \left( m^2 - \mu^2 + \frac{\mu^4}{4m^2} \right) - \left( - \mu^2 + \frac{\mu^4}{4m^2} \right) = m^2 \quad (\text{OK})$$

---

## 5. 結論

以上の計算が示すように、**空間運動量の $z$ 成分を純虚数に選ぶ**ことで、3つの粒子が同時にオンシェル（$p^2 = m^2, q^2 = \mu^2, (p+q)^2 = m^2$）であるような複素運動量の組 $(p^\mu, q^\mu)$ を具体的に構成することができました。

複素運動量空間への解析接続を行うことで、実運動量空間での運動学的な不可能性を回避し、繰り込み条件の数学的・物理的整合性が保たれています。
