# Part B 第1問 (6) 4点関数2次摂動係数 (8, 16, 16) の厳密導出検証ドキュメント

本ドキュメントは、ユーザー様のご指摘に基づき、複素スカラー場 $\lambda(\phi^*\phi)^2$ における 4点 2次摂動項の **純粋な Wick 収縮数** と **摂動展開因子 $\frac{1}{2!}$ を含めた最終係数 (8, 16, 16)** の厳密な数学的カウントを完全に検証・修正した決定版です。

---

## 1. 結論（ユーザー様のご指摘が 100% 正しい）

手書き図面 `n=4,k=2_complex.pdf` に記録された数値：
- **$s$-channel = 8**
- **$t$-channel = 16**
- **$u$-channel = 16**

は、**純粋な Wick 収縮数（16, 32, 32）に摂動展開の階乗因子 $\frac{1}{2!}$ を適用した後の「最終的な数式上の係数そのもの」** です。

したがって、数式における正しい 1PI 2次頂点補正の係数は **$8\lambda^2, 16\lambda^2, 16\lambda^2$** であり、問(8)における再規格化結合定数 $g$ の 2次補正の合計係数は **$8 + 16 + 16 = 40$** となります。

---

## 2. 各チャンネルの厳密なカウントステップ

相互作用ハミルトニアン密度 $\mathcal{H}_{\text{int}} = \lambda (\phi^* \phi)^2$ の 2次摂動展開式：

$$\frac{1}{2!} \int \mathrm{d}^4 z_1 \mathrm{d}^4 z_2 \, (-\lambda)^2 \left\langle 0 \left| \mathrm{T} \phi(x_1)\phi(x_2)\phi^*(x_3)\phi^*(x_4) \cdot (\phi^*\phi)^2(z_1) \cdot (\phi^*\phi)^2(z_2) \right| 0 \right\rangle$$

各頂点 $z_i$ は $2$ 個の $\phi$（出力線用）と $2$ 個の $\phi^*$（入力線用）を持ちます。

### (a) $s$-channel 1PI ループ
- **結合構造**: 入力 $\phi(x_1), \phi(x_2)$ が頂点 $z_1$ に、出力 $\phi^*(x_3), \phi^*(x_4)$ が頂点 $z_2$ に接続する（あるいはその逆）。
- **純粋な Wick 収縮数**:
  1. $x_1, x_2$ を $z_1$ の 2つの $\phi^*$ に結ぶ: $2! = 2$ 通り
  2. $x_3, x_4$ を $z_2$ の 2つの $\phi$ に結ぶ: $2! = 2$ 通り
  3. 内部ループ $z_1 \leftrightarrow z_2$ （$z_1$ の残り 2つの $\phi$ と $z_2$ の残り 2つの $\phi^*$ を結ぶ）: $2! = 2$ 通り
  4. 頂点ラベルの交換 ($z_1 \leftrightarrow z_2$): $2$ 通り
  - **純粋 Wick 収縮数** $= 2 \times 2 \times 2 \times 2 = 2^4 = \mathbf{16 \text{ 通り}}$
- **最終係数**: $\frac{1}{2!} \times 16 \times \lambda^2 = \mathbf{8 \lambda^2}$

---

### (b) $t$-channel 1PI ループ
- **結合構造**: 入力 $\phi(x_1)$ と出力 $\phi^*(x_3)$ が頂点 $z_1$ に、入力 $\phi(x_2)$ と出力 $\phi^*(x_4)$ が頂点 $z_2$ に接続する（あるいはその逆）。
- **純粋な Wick 収縮数**:
  1. $x_1$ を $z_1$ の $\phi^*$ に結ぶ: $2$ 通り
  2. $x_3$ を $z_1$ の $\phi$ に結ぶ: $2$ 通り
  3. $x_2$ を $z_2$ の $\phi^*$ に結ぶ: $2$ 通り
  4. $x_4$ を $z_2$ の $\phi$ に結ぶ: $2$ 通り
  5. 内部ループ $z_1 \leftrightarrow z_2$（$z_1$ の残り $(\phi, \phi^*)$ と $z_2$ の残り $(\phi^*, \phi)$ を結ぶ）: $1 \times 1 = 1$ 通り
  6. 頂点ラベルの交換 ($z_1 \leftrightarrow z_2$): $2$ 通り
  - **純粋 Wick 収縮数** $= 2 \times 2 \times 2 \times 2 \times 1 \times 2 = \mathbf{32 \text{ 通り}}$
- **最終係数**: $\frac{1}{2!} \times 32 \times \lambda^2 = \mathbf{16 \lambda^2}$

---

### (c) $u$-channel 1PI ループ
- **結合構造**: 入力 $\phi(x_1)$ と出力 $\phi^*(x_4)$ が頂点 $z_1$ に、入力 $\phi(x_2)$ と出力 $\phi^*(x_3)$ が頂点 $z_2$ に接続する。
- **純粋な Wick 収縮数**: $t$-channel と完全に等価な組み合わせ構造 $\implies \mathbf{32 \text{ 通り}}$
- **最終係数**: $\frac{1}{2!} \times 32 \times \lambda^2 = \mathbf{16 \lambda^2}$

---

## 3. 正しい数値の総括表

| チャンネル | 純粋な Wick 収縮パターン数 | 摂動展開因子 $\frac{1}{2!}$ | 数式における最終係数 |
| :--- | :---: | :---: | :---: |
| **$s$-channel** | **16** | $\frac{1}{2}$ | **$8 \lambda^2$** |
| **$t$-channel** | **32** | $\frac{1}{2}$ | **$16 \lambda^2$** |
| **$u$-channel** | **32** | $\frac{1}{2}$ | **$16 \lambda^2$** |
| **合計 (全1PIループ)** | **80** | $\frac{1}{2}$ | **$40 \lambda^2$** |

したがって、数式における項の全係数は手書きメモに書かれた数値 **$8\lambda^2, 16\lambda^2, 16\lambda^2$** と完全に一致します。
