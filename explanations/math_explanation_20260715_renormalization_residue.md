# 散乱振幅の極における「伝播関数の分割」と繰り込み条件の物理的意味

このドキュメントでは、散乱振幅 $\bar{u}' \widetilde{\Gamma}' \widetilde{S}' \widetilde{\Gamma}' u$ において、射影演算子の性質（冪等性）を用いて伝播関数を左右に分配する代数的な手順と、その際の運動学的な意味（なぜ $q^2 = \mu^2$ で整合するのか）について詳しく解説します。

---

## 1. 教科書が言いたいことの核心（物理的な主張）

教科書（コールマン）がここで主張したい最も重要な結論は以下の一点です：

> **「1PI三点関数 $\widetilde{\Gamma}'$ には本来、高次補正によって様々なガンマ行列が入り混じった複雑な構造（16通りや42通りなど）があるが、物理的に測定可能なオンシェル散乱の『極の残差』を計算する際には、その複雑な構造のうち『射影演算子で挟まれた部分（＝スカラー関数 $G(q^2)$）』しか寄与しない。したがって、この挟まれた部分だけに繰り込み条件を課しておけば、物理的な極の残差は完全に定義される。」**

---

## 2. 伝播関数の「分割」の代数（なぜ両側の頂点を挟めるのか？）

散乱振幅 $\mathcal{M}$ において、中間状態の不変質量 $s = p_I^2 = (p+q)^2$ が核子質量 $m^2$ に近づく極（$s \to m^2$）の近傍を考えます。

振幅の形は以下の通りです：
$$\mathcal{M} \approx \bar{u}(p') \widetilde{\Gamma}'(p', p_I, q') \left[ \frac{i(\not p_I + m)}{s - m^2} \right] \widetilde{\Gamma}'(p_I, p, q) u(p)$$

この極 $s \to m^2$ において、分子にある $\not p_I + m$ は、オンシェル上のディラック射影演算子 $\Lambda(p_I) = \frac{\not p_I + m}{2m}$ に比例します。
射影演算子には、**「2回掛けても1回掛けるのと同じ（冪等性 $\Lambda^2 = \Lambda$）」**という重要な性質があります。式で書くと：
$$\not p_I + m = 2m \Lambda(p_I) = 2m \Lambda(p_I)^2 = 2m \left( \frac{\not p_I + m}{2m} \right) \left( \frac{\not p_I + m}{2m} \right) = \frac{(\not p_I + m)(\not p_I + m)}{2m}$$

この性質を利用して、極の分子にある $\not p_I + m$ を**「2つの射影演算子の積」**に分割して、左右の頂点にそれぞれ分配します：
$$\begin{aligned}
\mathcal{M} &\approx \frac{i}{s - m^2} \bar{u}(p') \widetilde{\Gamma}'(p', p_I, q') \left[ \frac{(\not p_I + m)(\not p_I + m)}{2m} \right] \widetilde{\Gamma}'(p_I, p, q) u(p) \\
&= \frac{i}{s - m^2} \frac{1}{2m} \left( \bar{u}(p') \widetilde{\Gamma}'(p', p_I, q') (\not p_I + m) \right) \left( (\not p_I + m) \widetilde{\Gamma}'(p_I, p, q) u(p) \right)
\end{aligned}$$

さらに、外線スピノールに対するディラック方程式の性質 $\bar{u}(p') = \bar{u}(p') \frac{\not p' + m}{2m}$ および $u(p) = \frac{\not p + m}{2m} u(p)$ を使うと、外線の両端にも射影演算子を自由に挿入できます。

最終的に、振幅は以下のように完全に「射影された頂点」の積に分解されます：
$$\mathcal{M} \approx \frac{i}{s - m^2} \frac{1}{8m^3} \bar{u}(p') \left[ \underline{(\not p' + m) \widetilde{\Gamma}'(p', p_I, q') (\not p_I + m)} \right] \left[ \underline{(\not p_I + m) \widetilde{\Gamma}'(p_I, p, q) (\not p + m)} \right] u(p)$$

この大括弧 `[...]` の中身は、左右ともに**「ディラック射影演算子で挟まれた頂点関数」**の形になっています。

---

## 3. なぜ $q^2 = \mu^2$ で整合するのか？（運動学の再整理）

ここで、右側の頂点 $(\not p_I + m) \widetilde{\Gamma}'(p_I, p, q) (\not p + m)$ に注目します。
この頂点で、各粒子の運動量はどうなっているでしょうか？

1. **フェルミオン $p$**: 物理的な外線核子なので、最初からオンシェルです（$p^2 = m^2$）。
2. **フェルミオン $p_I$**: 散乱振幅の極限 $s \to m^2$ を取っているため、オンシェルになります（$p_I^2 = s = m^2$）。
3. **メソン $q$**: 物理的な外線メソンなので、オンシェルです（$q^2 = \mu^2$）。

ユーザーのご指摘の通り、**実運動量の範囲では、これら 1, 2, 3 を同時に満たす運動量は存在しません**。
しかし、この極限を考えている時点で、運動量は**複素運動量（複素数領域）に解析接続されています**。

複素運動量の世界では、
- $p^2 = m^2$
- $p_I^2 = m^2$
- $q^2 = \mu^2$
を同時に満たす複素運動量のセット $(p, q)$ が**数学的に矛盾なく存在します**。

したがって、極の点において、この右側頂点は**「2つのフェルミオンがオンシェルで、メソンが $q^2 = \mu^2$」**という条件を正確に満たしています。

コールマンが定義した繰り込み条件：
$$\left. (\not p_I + m) \widetilde{\Gamma}'(p_I, p, q) (\not p + m) \right|_{p^2 = p_I^2 = m^2, q^2 = \mu^2} = (\not p_I + m) i \gamma_5 (\not p + m) g$$
は、まさにこの複素運動量上の点における値（結合定数）を $g$ と定義する、という条件です。

したがって、解析接続された極 $s \to m^2$ において、この右側頂点の値は正確に $g$ になります（左側頂点も同様に $g$ になります）。
結果として、極における物理的な振幅は以下のように定まります：
$$\mathcal{M} \approx \frac{i}{s - m^2} \frac{1}{8m^3} \bar{u}(p') \left[ (\not p' + m) i \gamma_5 (\not p_I + m) g \right] \left[ (\not p_I + m) i \gamma_5 (\not p + m) g \right] u(p)$$

これは、我々が定義した結合定数 $g$ を用いて、極の残差が正しく決定されることを示しています。

---

## 4. 結局、何を主張したいのか？

もし、このような射影演算子による定義をせず、三点関数 $\widetilde{\Gamma}'$ の全てのガンマ行列構造（例えば $\gamma_5 \not p$ など）に対して別々に繰り込み条件を課そうとすると、ラグランジアンにそんなに多くの種類の反項がないため、理論を繰り込むことができません。

しかし、この極の議論によって、
- **「散乱の極（物理的に測定される主要な寄与）を計算する際、射影演算子で挟まれていない余計な行列構造は、伝播関数の極の代数（冪等性）によってすべて消去されてしまい、極の残差には一切寄与しない」**
ということが示されました。

ゆえに、**「余計な行列構造のことは無視してよく、射影演算子で挟んだスカラー部分 $G(q^2)$ だけを $q^2 = \mu^2$ で $g$ と定義すれば、物理的な結合の強さを定義するには十分である」**というのが、教科書のこの部分のクリアな主張です。
