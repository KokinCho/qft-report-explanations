# フェルミオン結合定数の繰り込み条件における運動学的（Kinematics）整合性と解析接続

このドキュメントでは、「三粒子オンシェル条件の不可能性」という運動学的な疑問と、それに対する「複素運動量空間への解析接続」を用いた解決、および繰り込み条件 $G(\mu^2) = g$ と散乱振幅の極の残差がどのように整合しているのかについて詳しく解説します。

---

## 1. 運動学的な問題の所在（ユーザーの指摘の通り）

頂点 $N(p) \to N(p_I) + \phi(q)$ （あるいは $N(p) + \phi(q) \to N(p_I)$）を考えます。
ここで、3つの粒子をすべて同時に実数のオンシェル（質量殻上）に置く条件を書き出してみます：
- 初期核子： $p^2 = m^2$
- 中間核子： $p_I^2 = s = m^2$
- メソン： $q^2 = \mu^2$ （ここで $\mu > 0$ はメソンの質量）

運動量保存則 $p_I = p + q$ より、両辺の二乗をとると：
$$p_I^2 = (p+q)^2 = p^2 + q^2 + 2p \cdot q$$
これにオンシェル条件を代入すると：
$$m^2 = m^2 + \mu^2 + 2p \cdot q \implies 2p \cdot q + \mu^2 = 0 \tag{1}$$

ここで、初期核子の静止系（$\mathbf{p} = \mathbf{0}$, $p^2 = m^2 \implies p^0 = m$）で考えてみます。
すると、内積 $p \cdot q$ は以下のように書けます：
$$p \cdot q = p^0 q^0 - \mathbf{p} \cdot \mathbf{q} = m q^0$$
メソンもオンシェルなので、$q^0 = \sqrt{\mathbf{q}^2 + \mu^2}$ です。これを式 (1) に代入すると：
$$2m \sqrt{\mathbf{q}^2 + \mu^2} + \mu^2 = 0 \tag{2}$$

しかし、質量 $m, \mu$ は正の実数であり、根号 $\sqrt{\mathbf{q}^2 + \mu^2}$ も正の実数です。したがって、式 (2) の左辺は常に正の値となり、**実数の運動量空間（物理的な領域）では、この方程式を満たす解（実運動量 $\mathbf{q}$）は存在しません。**

もしメソンが質量ゼロ ($\mu = 0$) だとしても、式 (2) は $2m |\mathbf{q}| = 0 \implies \mathbf{q} = \mathbf{0}$ となり、メソンの運動量 $q^\mu$ がすべて 0 になるという自明な（物理的に意味のない）解しか存在しません。

したがって、**「実数の運動量の範囲では、3点すべてを同時にオンシェルにすることは不可能である」**というユーザーのご指摘は完全に正しいです。

---

## 2. 解析接続（Analytic Continuation）による解決

この運動学的な不可能性を解決するために、量子場論では**「複素運動量空間への解析接続」**を行います。

### 解析接続とは
散乱振幅（S行列）や頂点関数は、運動量変数の（特定の領域で定義された）実関数ではなく、複素運動量変数に対する**複素解析関数**として扱われます。
物理的な散乱が起こる領域は、エネルギー $s \ge (m + \mu)^2$ という実軸上の領域（物理的領域）ですが、数式としては $s$ や $q^2$ を複素数に拡張することができます。

### 複素運動量でのオンシェル条件
複素運動量空間の中では、実数のエネルギー保存則の制限を超えて、3つの条件：
1. $p^2 = m^2$
2. $p_I^2 = m^2$
3. $q^2 = \mu^2$
を同時に満たす複素運動量のセット $(p^\mu, p_I^\mu, q^\mu)$ を数学的に選ぶことが可能です。

コールマンが提案している繰り込み条件：
$$G(q^2) \Big|_{q^2 = \mu^2} = g \tag{23.96}$$
は、まさにこの**「3点すべてがオンシェルになるように解析接続された複素運動量の点」**において課されている条件です。

---

## 3. 散乱振幅の極（ポール）の残差との整合性

では、実際の物理的な散乱プロセス（例えばメソン-核子散乱 $\phi + N \to \phi + N$）と、この繰り込み条件はどのように整合するのでしょうか？

議論の流れは以下のようになります：

1. **物理的散乱の開始**:
   物理的な散乱領域（$s \ge (m+\mu)^2$、かつ外線はすべて実オンシェル $p^2=m^2, q^2=\mu^2$）から出発します。このとき、中間状態の不変質量 $s = (p+q)^2$ は $m^2$ より大きいため、伝播関数 $\widetilde{S}'(p+q) \sim \frac{i}{s - m^2}$ は有限の値を持ちます。
   
2. **極への解析接続**:
   散乱振幅を $s$ に関して複素平面上で解析接続し、$s \to m^2$ という極の極限を取ります。
   * この極限操作の間、**外線のオンシェル条件 $p^2 = m^2$ および $q^2 = \mu^2$ はずっと維持したまま**にします。
   * $s \to m^2$ に近づくにつれて、中間状態の運動量 $p_I = p+q$ はオンシェル（$p_I^2 \to m^2$）に近づいていきます。

3. **極における頂点関数の値**:
   極 $s = m^2$ に到達した瞬間、頂点 $\widetilde{\Gamma}'(p_I, p, q)$ に流れ込む運動量は以下の条件をすべて満たしています：
   * $p^2 = m^2$ （外線核子がオンシェル）
   * $p_I^2 = m^2$ （中間核子がオンシェル）
   * $q^2 = \mu^2$ （外線メソンがオンシェル）
   
   これは、まさにステップ2で説明した**「3粒子がすべてオンシェルになる解析接続された点」**そのものです！
   
4. **残差の決定**:
   したがって、極の残差に現れる射影された頂点関数の値は、繰り込み条件（23.96）によって定義された値そのもの、すなわち以下になります：
   $$\left. (\not p_I + m) \widetilde{\Gamma}'(p_I, p, q) (\not p + m) \right|_{\text{pole}} = (\not p_I + m) i \gamma_5 (\not p + m) G(\mu^2) = (\not p_I + m) i \gamma_5 (\not p + m) g$$
   
   この結果、極の残差を計算したときの結合定数は、我々が定義した物理的結合定数 $g$ に正確に一致します：
   $$\text{Residue} \propto g^2$$

### 結論（議論の順番）
物理的な散乱から始めて「極の残差」を求めるというプロセスは、必然的に運動量を複素数へと解析接続する操作を含んでいます。
繰り込み条件は、その解析接続された極の点における頂点関数の値を $g$ と定義しているため、何ら矛盾することなく完璧に整合しています。
すなわち：
- **実世界（実運動量）**： $s = m^2$ と $q^2 = \mu^2$ は両立しない（散乱振幅に極は現れない）。
- **複素世界（解析接続）**： $s = m^2$ と $q^2 = \mu^2$ は両立する。散乱振幅は $s = m^2$ に極（複素極）を持ち、その残差が繰り込み条件で定義された $g^2$ に一致する。
- 物理的な測定（実軸上での散乱断面積など）は、この複素極の影（ブライト・ウィグナー分布など）として観測されます。
